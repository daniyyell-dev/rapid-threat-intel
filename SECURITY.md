# Security policy

## Reporting a problem

Please report these privately, not in a public issue:

- An indicator that would cause serious harm if blocked, such as a widely used legitimate service
- A file or query in this repository that is unsafe to use
- Sensitive or personal data published here by mistake

How to report:

1. **GitHub:** use **Report a vulnerability** on the repository's [Security tab](https://github.com/daniyyell-dev/rapid-threat-intel/security) if it is available.
2. **LinkedIn:** send a direct message to [Daniel Jeremiah](https://www.linkedin.com/in/daniel-jeremiah).

Include the file path, the indicator or line affected, and why it is a problem. You will get a reply as soon as possible, and confirmed issues are fixed or removed promptly.

For ordinary false positives, open a [false-positive issue](https://github.com/daniyyell-dev/rapid-threat-intel/issues/new?template=false-positive.yml).
