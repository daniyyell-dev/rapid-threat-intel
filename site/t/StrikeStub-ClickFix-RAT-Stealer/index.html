Summary

Note Single-source indicators (Akamai). The C2 host and port are config-driven and were not published. spiraldirect[.]ch is a compromised legitimate site: alert only, do not block it as attacker infrastructure.

What to do

  1. Block squidscript[.]com and hxxp://squidscript[.]com/Cloudflare.exe (they are in the Defender XDR import file).
  2. Hunt for explorer.exe launching hidden PowerShell that uses iwr or irm to write %TEMP%\svc.exe, for RuntimeBroker.exe running outside System32, and for WindowsUpdate.exe in a user Run key or Startup folder.
  3. Search proxy, firewall and TLS-inspection logs for the WebSocket user agent StrikeStub/1.0; the C2 address was not published.
  4. Treat spiraldirect[.]ch as a compromised site: alert on visits and review the host, but do not block the legitimate domain as if it were attacker infrastructure.
  5. If confirmed, isolate the host, remove the Run-key and Startup persistence, and rotate browser and other credentials that may have been taken through DPAPI.

Background

Akamai, writing on 12 November 2026, describes StrikeStub, a modular Windows remote access trojan and stealer likely sold as malware-as-a-service, delivered through a ClickFix lure on the compromised site spiraldirect[.]ch. A fake 'Verify you are human' prompt copies a hidden PowerShell command that downloads hxxp://squidscript[.]com/Cloudflare.exe to %TEMP%\svc.exe and runs it. The payload masquerades as RuntimeBroker.exe with spoofed Microsoft version resources, persists as Microsoft\WindowsUpdate.exe through a Registry Run key and the user Startup folder, and talks to a config-driven C2 over WebSockets with the user agent StrikeStub/1.0. Operators can toggle hidden VNC, keylogging, webcam capture, live desktop streaming, clipboard monitoring and DPAPI theft of browser credentials. squidscript[.]com and the Cloudflare.exe URL are attacker infrastructure and are on the block list; spiraldirect[.]ch is a compromised legitimate site and is alert only. Akamai did not publish a sample hash or the C2 host, which is read from a runtime config, so hunt on the behaviours and the user agent as well as the staging URL.
