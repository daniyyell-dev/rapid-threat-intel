More detail
Note The landing domains were short-lived and sat behind Cloudflare; those Cloudflare anycast addresses also serve unrelated sites and must not be blocked. NetSupport Manager is legitimate remote administration software: block only the attacker staging and gateway infrastructure, and hunt the ClickFix command and mestos2.zip install path rather than the product name alone. EfficientIP did not publish a sample hash or confirm victims.

What to do

  1. Block the seven apartments-review*.sbs landing domains, 89[.]34[.]90[.]203, the /winup2 and /mestos2.zip URLs, the nine gateway domains and the two Flyservers addresses (they are in the Defender XDR import file), and search 90 days of DNS, proxy and firewall logs for them and for the decimal address 1495423691.
  2. Hunt for explorer.exe launching PowerShell that uses iwr to fetch winup2, for %TEMP%\winup2.ps1, and for a Startup-folder NetSupport.lnk whose target is Service.exe under %APPDATA%\NetSupport after a hidden PowerShell or Python download.
  3. Treat genuine NetSupport Manager installs as legitimate; do not block the product. If a host ran the ClickFix command, isolate it, remove the Startup shortcut and the %APPDATA%\NetSupport copy, and rotate credentials the logged-on user could reach.

Background

EfficientIP Research Labs, writing on 12 November 2026, traces a ClickFix campaign that used fake Zillow apartment-review pages on short-lived apartments-review<digits>.sbs domains, first spotted in passive DNS in August 2026. Clicking Continue copied a PowerShell command that fetched a script from the decimal address 1495423691, which is 89[.]34[.]90[.]203, at /winup2. The script hid its window, used a downloaded Python runtime to pull hxxp://89[.]34[.]90[.]203/mestos2.zip, installed NetSupport RAT into %APPDATA%\NetSupport and dropped a NetSupport.lnk shortcut in the user Startup folder pointing at Service.exe. The installed client was configured to use the gateway domains asgomd[.]com and asgrsv[.]com; pivoting on their Flyservers addresses 45[.]227[.]254[.]179 and 45[.]227[.]254[.]10 uncovered seven further short -md and -rsv domains on the same hosts. Help Net Security reported the same findings on 13 November. The landing domains, payload host, URLs and gateway infrastructure are on the block list. Do not block the Cloudflare addresses that only fronted the short-lived landing pages, and do not treat legitimate NetSupport Manager as malware.
